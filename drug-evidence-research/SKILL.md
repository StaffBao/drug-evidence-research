# 药物临床证据研究

把问题变成可核查的研究：**明确比较对象 → 找到原始证据 → 重建试验方案 → 判断可比性 → 解释结论及边界 → 清楚呈现**。方法可用于不同治疗领域；GLP-1 是案例来源，不是适用范围的限制。

## 运行方式

使用当前助手可用的文件读取、检索和输出工具完成任务。本技能不指定产品、模型、工具名称或专属调用命令。包内链接相对于技能文件夹；按需读取相应参考文件。手动加载时，也应实际读取任务所需的参考内容；无法访问时说明材料范围。

仅分析提供的材料时可离线使用；研究当前证据需要检索与原文读取能力。制作报告或幻灯片时，采用用户指定形式以及当前环境可用的工具。

## 开始时确定什么

从用户问题和现有材料提取：目标决策、具体药物或配方、单药还是组合、目标人群、地区、证据截止日和交付形式。已有上下文足够时直接研究；只询问会改变结论的缺失条件。

窄问题交付直接答案与必要证据，不自动扩成全行业报告。用户要求综合研究时，再展开机制、设计、结果、风险和开发状态。保留指定的文件、产品及既有结构；这个 Skill 不自动指定 Slides、HTML 或其他平台，也不授予外发、发布或上传权限。

研究当前状态时检索并核查原始来源；仅处理用户给定材料时说明覆盖范围。不能访问关键原文时标明缺口，区分“摘要已核”“原文未取得”“尚未找到”，不补造数据。

## 核心工作方式

### 1. 建立对象与证据清单

为分子、受体、品牌、配方、给药途径及剂量方案分别命名。组合写出每个成分、各自剂量、途径与频率，不能只写“二联”“司美”“2.4/2.4”让读者猜。

按问题选来源：批准和标签看监管原文；试验设计看方案、统计分析计划和登记；效果和安全性看论文、补充材料或正式结果表；公司开发决定看有日期的公司原话。新闻可帮助定位，不能替代可获得的原始依据。详见 [证据与研究记录](references/evidence-and-records.md)。

每个关键结论保留具体定位、证据类型、适用对象及核查日。把“来源直接报告”“自行计算”“模型估计”“机制推断”写清楚。发现冲突先核对版本、时点、分析集和定义，不挑选最漂亮的数字。

### 2. 重建试验，再比较结果

先列清分组、实际受试者人数、共同背景治疗、剂量递增、随访与主要终点，再解读疗效和安全性。使用 [临床比较与安全性](references/trials-and-safety.md) 处理多臂试验、非劣效、分析口径和不良事件。

区分随机人数、接受治疗人数、安全集和各终点可分析人数。停药、救援治疗等如何处理可能改变回答的问题；不要把治疗策略估计与持续按方案用药估计混用。不同研究的数据可以并列介绍，不能直接相减并宣称随机比较优势。

对没有确证检验、稀少事件或随访不足的结果保留不确定性。没有显著差异不等于等效；未达非劣不等于无效或终止开发。安全性没有足够证据时，结论应当停在证据所能支持的位置。

### 3. 解释机制，建立完整因果链

按照“什么分子 → 哪些细胞产生 → 如何加工或激活 → 作用于什么受体和细胞 → 正常承担什么功能 → 药物在哪一步改变什么 → 临床上证实了什么”解释。先给可理解的生理学描述，再放缩写和图。

机制、口服吸收、药代动力学和证据桥接需要时读 [机制与制剂比较](references/mechanisms-and-pk.md)。不要由吞服的 mg 推出血中暴露或毒性倍数，也不要把同一分子或暴露相近写成全面安全等同。

### 4. 分开描述研究结论与现实状态

涉及开发是否停止、哪国获批、适应症扩展或法律责任时，读 [批准与开发状态](references/approvals-and-development.md)。临床结果、监管决定、企业决定、登记状态和司法程序分别列证据；不靠其中一个替另一个下结论。

### 5. 让读者一眼看清

保留关键细节，通过表格、流程和分层说明降低理解成本。两个以上剂量、多个研究组或一串对应数字优先逐行列表。每列清楚标明时点、单位、分析集、对照和来源；未报告写“未报告”，不能写成 0。

需要报告、幻灯片或交互说明时读 [呈现与迭代](references/presentation-and-updates.md)。现有成品中的更新要同步检查正文、表格、弹窗、目录与脚注，保留用户排序和稳定链接；只修改本次涉及的内容。

## 默认交付

随问题复杂度选择以下内容，不强制每次都输出全部：

- **直接回答**：结论、适用人群与方案、最关键的限制。
- **比较表**：设计和分组；疗效；安全性。复杂时分表，不挤成一张大表。
- **证据依据**：能直接支持相邻主张的原始链接，以及必要的页码、表号或条款。
- **证据空白**：哪些尚未报告、只是模型或间接证据，什么新信息会改变判断。

长期项目可复制 [研究记录模板](assets/research-record.template.json)，报告可用 [报告骨架](assets/report-template.md)。模板按任务裁剪，不为填满字段而扩大研究。口服与注射的历史示例见 [工作示例](references/worked-example.md)，其中数字只用于演示方法，使用时重新核查相关证据。

## 完成前核对

对照原表复核会改变结论的剂量、分母、时点、单位、主要终点与统计口径；抽查链接确实支持相应主张。观察性关联、动物证据、模型或探索性分析不能在压缩文字后变成确证临床结论。

检查读者能否回答：比较的是谁、用了什么方案、和谁比、多久、结果是什么、风险是什么、还不能证明什么。报告事实与推断，避免为了表达“信心”放大结论。
