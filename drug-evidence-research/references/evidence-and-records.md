# 证据与研究记录

在规划检索、核对矛盾或维护长期研究时读取。

## 把模糊问题变成研究问题

例如“口服剂量大是否更危险”至少有三个层次：标称剂量是否更大、系统暴露是否更高、临床风险是否更高。分别找证据，不让一个指标代替整条因果链。

为比较对象建立身份卡：通用名、开发代号、商品名、厂家或当前权利方、分子类型、配方版本、途径、目标剂量及递增方案。只有用户问题需要时才追溯历史权属。不同品牌可能是同一分子，不同配方未必可按 mg 互换。

## 按主张检索，而不是按网页数量研究

| 要回答的主张 | 首要来源 | 核查内容 |
|---|---|---|
| 研究如何设计 | 方案、统计分析计划、登记与历史版本 | 终点、比较、分层、盲法、估计目标、样本量、变更时间 |
| 疗效与不良事件 | 完整原始论文、补充材料、正式登记结果表 | 具体表格、人数、时点、分析集、脚注、预设与探索性 |
| 当前能批准用于谁 | 对应地区正式决定与现行标签 | 分子、剂型、品牌、剂量、年龄、疾病、用途与生效日 |
| 为什么准许桥接 | 监管审评、原始 PK/BE 研究及模型 | 哪些结局和人群被桥接、假设、变异及局限 |
| 公司是否继续开发 | 有日期的公司公告、投资者资料或直接表态 | 是分子、某个方案、某适应症还是某个项目部分 |
| 正常生理与机制 | 原始机制实验、人体研究；必要时用权威综述定位 | 细胞来源、分子形态、物种、干预和结局 |
| 诉讼或监管行动 | 法院、监管机构等原始文件 | 主张、程序节点、认定事实与因果结论是否不同 |

没有一条机械的“所有问题都先看 RCT”排序；来源是否合适取决于它能否回答该主张。企业公告可直接证明企业的计划，却未必足以证明其疗效解释。

搜索时组合通用名与开发代号、试验名与登记号、方案或补充材料、监管地区与具体用途。找到失败或停止信息时，还要核对具体终点、后续官方说明和对应研究部分，避免把早期新闻当当前状态。不得把搜索摘要当已核实全文。

## 最小证据记录

一项可复核主张需要：

- 主张 ID、准确表述，以及对象／人群／方案／地区／时点。
- 来源标题、机构、原始链接、发布日期与核查日期；关键表格、页码、条款或登记历史定位。
- 来源性质与访问范围：完整原文、摘要、部分表格、官方公告或二手报道。
- 数值的分子、分母、单位、分析集和估计目标；计算值另写公式。
- 证据方式：直接比较、间接描述、模型估计、机制推断，或仅为企业计划。
- 能支持的结论、不能支持的外推，以及冲突和缺失数据。

可用稳定 ID 将“主张 → 来源 → 表格行 → 报告段落或幻灯片”连接起来。原始提取值与后来生成的文字分开保存，避免改写后的文字成为自己的证据。

## 遇到冲突时

先检查是否其实在说不同的问题：随机集与安全集、受试者数与事件数、治疗期与随访期、主要时点与延长期、停药纳入与持续用药假设、初步公告与最终分析、标签初批与扩展用途。能解释就写清对应关系；不能解释时并列来源和差异，不取平均、不挑最大值。

更新时保留旧结论的截止日及变更原因。新材料只有计划就记录计划，不能把预计完成日当已完成日。若用户只让检查现有材料，标明“在提供材料范围内”，不冒充完成全面系统综述。

## 研究范围如何表述

有针对性的原始证据核查不自动等于系统综述或 Meta 分析。只有实际执行了可重现的检索策略、纳排标准、筛选、偏倚评价和适当综合，才使用相应名称。没有执行的步骤不在方法中写成已完成。
